== Synopsis

aerospace unmark [-h|--help] [--window-id <window-id>] [<mark>]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

`unmark <mark>` removes that mark from whichever window has it; `unmark` alone removes every mark
from every window. With `--window-id`, only that window's marks are touched.
