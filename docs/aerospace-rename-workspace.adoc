aerospace rename-workspace [-h|--help] [--workspace <workspace>] [--] <new-name>

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

Renames the focused workspace (or `--workspace`). Its windows, monitor and focus stay as they are,
and `workspace-back-and-forth` keeps working across the rename. Fails if a workspace named
`<new-name>` already exists.
