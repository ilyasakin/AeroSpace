:manpurpose: Move the focused window (or focused container) next to the marked window
// end::purpose[]

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospace move-node-to-mark [-h|--help] [--window-id <window-id>] [--focus-follows-window] <mark>

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

i3's `move container to mark`: the node lands right after the marked window, as its sibling, on the
marked window's workspace. If the marked window floats, the moved window becomes floating there.

// =========================================================== Options
include::./util/conditional-options-header.adoc[]

-h, --help:: Print help

--window-id <window-id>::
include::./util/window-id-flag-desc.adoc[]

--focus-follows-window:: Focus the moved window afterwards.
