// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

`scratchpad move` (i3 `move scratchpad`) makes the window floating and hides it in the scratchpad,
a workspace that is never shown or listed. With `focus parent`, every window of the focused
container goes.

`scratchpad show` (i3 `scratchpad show`):

* the focused window is a scratchpad window: it is hidden again;
* a scratchpad window is visible on this workspace but not focused: it is focused;
* otherwise the most recently used hidden scratchpad window is shown floating on the focused
  workspace — centred the first time, where you left it afterwards.

With `--window-id` or criteria (`[app-id="com.spotify.client"] scratchpad show`) that particular
window is toggled. A scratchpad window stops being one when it is tiled again (`layout tiling`).
